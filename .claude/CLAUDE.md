# Backend:
- Aufbau einer REST-API mit Spring Boot und Dokumentation der Schnittstellen über Swagger
  - Spring: https://spring.io/guides/gs/rest-service/
  - Swagger: https://spring.io/projects/spring-restdocs
- Webservice soll ein komplettes CRUD auf eine Ressource beinhalten (z.B. Todo-Liste)
- Beispiel DB Anbindung: https://spring.io/guides/gs/accessing-data-mongodb/

# Frontend:

- Erstellung einer Single Page Application mit Angular unter Verwendung der Angular CLI https://cli.angular.io/
- Anbindung an REST-API via Angular HttpClient
- CRUD Operationen auf mehrere Angular Seiten unterteilen Routing verwenden
- Frontend Unit-Tests mit Jasmine Test-Framework Angular CLI: ng test
- Frontend UI-Tests mit Protractor Angular CLI ng e2e
